# 《第7盏灯》v5.3 战斗视觉升级设计

日期：2026-09-29  
目标版本：Web v5.3.0 / Windows v1.1.0

## 1. 目标

本轮以“视觉更炸裂，但攻击仍看得清”为核心，统一升级主角攻击、普通敌人受击与死亡、百口灯妖阶段转换和最终击败演出。

成功标准：

- 普通三连击、蓄力重击和祭刃攻击有明确的轻重层级。
- 普通敌人受击方向清楚，死亡不再突然消失。
- 百口灯妖每种攻击的前兆、方向和真实危险区域一致。
- Boss 阶段切换和最终击败形成可辨认的短电影式高潮。
- 视觉升级不改变谜题、章节进度、存档格式和现有难度数值。
- 关闭镜头冲击、关闭闪光或启用系统“减少动态效果”后，强刺激反馈同步减弱。

## 2. 范围

### 2.1 主角攻击

- 普通三连击分别使用轻击、重击、终结击三级反馈。
- 蓄力重击增加聚灯、攻击残影、冲击环和更强的短定帧。
- 戏魂祭刃的连斩与突进保留现有判定，仅补足运动轨迹和命中层级。
- 命中反馈必须根据攻击方向生成，不能只做随机屏幕抖动。

### 2.2 普通敌人

- 受击时按来向生成纸屑、火花、微位移和短暂轮廓闪光。
- 重击命中与普通命中使用不同的粒子数量、冲击环尺寸和音画权重。
- 敌人死亡改为“撕裂—散纸—余烬消退”三段式，不改变掉落与进度触发时机。
- 敌人判定、血量、攻击间隔和难度倍率保持不变。

### 2.3 百口灯妖

- 现有三阶段和回响模式第四阶段保留。
- 每种攻击继续显示文字前兆，并新增与真实攻击方向同步的地面危险区或弹道引导线。
- 阶段切换约 0.7 秒：清理残留攻击、短暂无敌、背景压暗、灯口依次点亮、冲击波爆发，再进入下一阶段。
- 虚相辨声机制保持不变，新增灯光命中嘴部时的声纹与聚焦反馈。
- 最终击败演出采用“百口爆灯—纸身崩解—第一盏归位—环境安静”的节奏。

## 3. 技术结构

新增 `game/combat_fx.js`，作为独立的战斗表现层。它负责：

- 攻击残影、冲击环、方向火花和纸屑。
- Boss 危险区域、阶段切换和死亡演出状态。
- 粒子池、屏幕特效上限和低动态降级。
- 向自动诊断接口暴露当前特效数量与演出阶段。

`game/game.js` 继续拥有战斗判定、伤害、敌人状态、Boss AI 和存档逻辑，只在以下节点向表现层发送事件：

- `player-hit-light`
- `player-hit-heavy`
- `enemy-defeated`
- `boss-telegraph`
- `boss-phase-transition`
- `boss-defeated`

表现层不得反向修改生命值、碰撞体、攻击计时或章节进度。这样即使特效系统异常，战斗仍可继续。

## 4. 数据流与降级

1. 战斗逻辑确认命中或状态变化。
2. `game.js` 发送包含位置、方向、强度、攻击类型和阶段的事件。
3. `combat_fx.js` 根据设置与性能预算选择效果组合。
4. 世界特效在角色与前景之间绘制；屏幕特效在 HUD 之前绘制；危险区始终高于装饰粒子。
5. 达到上限时，先淘汰最旧的装饰粒子，不淘汰危险区和阶段状态。

降级规则：

- `screenShake=false`：取消方向镜头冲击，只保留局部视觉效果。
- `flash=false`：取消全屏闪光，保留低亮度冲击环。
- `prefers-reduced-motion: reduce`：取消强定帧、持续震动和多层残影，保留判定提示。
- 表现层未加载或抛出错误：记录到 `window.__GAME_ERRORS__`，游戏逻辑继续运行。

## 5. 战斗节奏约束

- Boss 前兆继续保持约 0.46–0.70 秒，不缩短现有玩家反应窗口。
- 阶段演出期间 Boss 无敌并清理旧弹幕，玩家不会被不可读的残留攻击命中。
- 引灯、夜行、无明、回响的伤害、生命、闪避无敌帧和弹幕速度沿用 v5.2.0。
- 新增视觉定帧只影响渲染与表现，不改变固定步长模拟结果。
- 任何镜头位移都必须在演出结束后平滑归零，不能改变角色世界坐标。

## 6. 验证

### 6.1 自动检查

- `game.js`、`motion.js`、`audio_manager.js`、`production_assets.js` 和 `combat_fx.js` 全部通过 `node --check`。
- `window.__GAME__` 保留现有字段，并新增只读 `combatFx` 诊断数据。
- 检查特效数量始终不超过硬上限。
- 检查关闭镜头冲击、关闭闪光和低动态偏好后的降级结果。

### 6.2 场景验收

- 主角普通三连击、蓄力重击、祭刃连斩和突进。
- 普通敌人轻击受伤、重击受伤和死亡。
- 百口灯妖第一至第三阶段、回响第四阶段、虚相辨声、阶段转换和最终击败。
- Boss 战中死亡重生、暂停恢复、窗口失焦恢复和旧存档继续。
- 击败 Boss 后正常保存并进入无面戏楼，不出现软锁。

### 6.3 性能

- 保留现有固定 60 Hz 模拟与粒子上限。
- 新特效使用对象复用和硬上限；拥挤时优先舍弃装饰粒子。
- 不加入大型视频、新图集或额外远程资源。
