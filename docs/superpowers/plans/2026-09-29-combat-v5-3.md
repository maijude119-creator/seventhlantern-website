# 《第7盏灯》v5.3 战斗视觉升级 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变存档格式和现有难度数值的前提下，完成主角、普通敌人和百口灯妖的统一战斗视觉升级，并发布 Web v5.3.0 与 Windows v1.1.0。

**Architecture:** 新增独立 `game/combat_fx.js` 表现层，通过事件接收命中、死亡、Boss 前兆与阶段变化；`game/game.js` 继续独占战斗判定和进度。表现层失败时自动降级，不能阻断游戏循环。

**Tech Stack:** 原生 JavaScript、Canvas 2D、HTML/CSS、Node.js 内置测试运行器、ZIP/GitHub Releases、Vercel。

**Spec:** `docs/superpowers/specs/2026-09-29-combat-v5-3-design.md`

## Global Constraints

- SAVE_VERSION 保持 `5`，不得迁移或清除现有玩家存档。
- 引灯、夜行、无明、回响的伤害、生命、闪避无敌帧和弹幕速度保持 v5.2.0 数值。
- 不增加大型视频、新图集、外部依赖或远程运行时资源。
- 特效异常不得修改生命、碰撞、AI、攻击计时或章节进度。
- Web 版本为 `v5.3.0`；Windows 版本为 `v1.1.0`。
- Windows v1.0.0 Release 必须保留作为回退版本。

## Review Focus

- 特效层不存在或抛错时，游戏仍能正常命中、击败敌人和推进 Boss。
- 粒子达到上限时，危险区与阶段状态仍保留，装饰粒子先被淘汰。
- `screenShake=false`、`flash=false`、`prefers-reduced-motion` 均能独立降级。
- Boss 阶段切换会清除旧弹幕，不会在演出期间伤害玩家或软锁。
- Windows ZIP 从任意解压目录启动时，相对图片、音频和脚本路径均有效。
